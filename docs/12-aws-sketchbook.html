How one step runs

jenkins/Jenkinsfile · job product-app-aws-terraform · parameters STEP and ACTION

The same loop, twelve times. Only the STEP parameter changes, and with it the Terraform resources that are targeted.

The finished picture

45 resources in the main state + 4 in the bootstrap state

Where every service sits once step 12 is done, and which way the traffic flows.

01Amazon S3Terraform state bucket

terraform/bootstrap/main.tf · 4 resources · about 1 min · ≈ $0

Terraform's memory. Every later step reads and writes its state file here, so this bucket comes first.

02Amazon VPCthe network

terraform/vpc.tf · 14 resources · about 1 min · free

The private network everything else lives in: one VPC, three kinds of subnet in two zones, and the routes that decide who reaches the internet.

03Security groupsthe firewall chain

terraform/security_groups.tf · 8 resources · free

Three firewalls that form a chain. Each layer only accepts traffic from the layer in front of it.

04AWS IAMroles for ECS

terraform/iam.tf · 3 resources · free · IAM is global

Two ID badges for ECS with no stored keys: one prepares the container, the other is the app's own.

05Amazon ECRthe image repository

terraform/ecr.tf · 2 resources · storage ≈ $0.10 per GB-month

The private shelf the Docker image is pushed to and ECS pulls from.

06Image to ECRbuild and push

jenkins/Jenkinsfile + product-app/Dockerfile · no Terraform · 2–5 min

Jenkins builds the same Dockerfile you use locally and uploads it. No Terraform runs in this step.

07AWS Secrets Managerthe database password

terraform/secrets.tf + iam.tf · 4 resources · ≈ $0.40 per month

Terraform invents the database password and locks it in a safe. Nobody ever types it.

08Amazon CloudWatch Logsthe log group

terraform/cloudwatch.tf · 1 resource · ≈ $0 until logs arrive

Where the container's output goes, because Fargate has no server you can log in to.

09Amazon RDSthe MySQL database

terraform/rds.tf · 2 resources · 8–12 min · ≈ $0.50 per day

The managed MySQL database, reachable only from the app's security group.

10NAT gatewaythe way out

terraform/vpc.tf · 5 resources · 1–2 min · ≈ $1.50 per day

The one-way door that lets tasks in private subnets reach AWS APIs.

11Application Load Balancerthe front door

terraform/alb.tf · 3 resources · 2–3 min · ≈ $0.80 per day

The only public entry point. It forwards requests to healthy tasks and checks /actuator/health.

12Amazon ECS on Fargatethe app starts

terraform/ecs.tf + ecs_service.tf · 3 resources · ≈ $0.70 per day

Where every earlier step meets: the recipe, the supervisor, and the app starting up.

Tearing it down

The Jenkins step destroy-all runs the same loop with terraform plan -destroy; you approve by typing destroy. Terraform deletes the 45 resources in reverse order: the ECS service first, the VPC last. The S3 state bucket from step 01 lives in its own configuration and stays until you delete it yourself.
